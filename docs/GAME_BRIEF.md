## Audience
Age 7 (primary). Easy to start, with depth to grow into.

## Character selection
- Player picks a character at the start.
- Options: skin tone (a range of tones), hair style and colour, outfit colour, and a few body and outfit styles.
- No real-world race labels. Skin tone choices only.
- Gender: offer a range of hair and outfit options so the player picks what they like. To be discussed with your son.
- Character choices are saved on the device only. No accounts, no personal data.

- Currency: gems. The basic in-game currency, earned by mining and playing.

## World and levels
- Open world that generates automatically (procedural generation), like Minecraft. Each world is different.
- The player starts in a home world (surface: grass, trees, water, hills).
- Caves: the player can dig down into caves from the surface. Caves hold gems, ores, and treasure, and get harder deeper down.
- Instances: the player can travel to other worlds (instances) that work like extra servers. Each instance is its own world that friends can join.
- Multiplayer safety: instances follow the same no-chat, preset-name rules as above. Players in an instance can build and mine together but cannot type to each other.

## Art style
Bright colours, bold outlines, squash-and-stretch animation, chunky blocky shapes like Minecraft.

## Monetization
None planned. Free, with no ads and no purchases.

## Open questions
- Name at signup: the game shows a short preselected list of randomly generated medieval names (e.g. Lord Kestrel 417, Mistress Elowen 82, Sir Brannoc 905). Each new setup generates a fresh list, and the player picks one from it.
- Name format: a generic medieval title (Lord, Mistress, Sir, Dame) + a generic medieval name + a random number. Built from preset word lists, never free-typed.
- Each player who joins a world gets the same kind of preselected list. Names can be changed later in Settings using gems.
- Multiplayer safety: names are visible to other players, so no free-typed names or chat. Names chosen from a safe preset list only.
- Character powers (all from the levelling system): digging speed, building speed, inventory capacity (more room to carry materials)
- Levelling system: each level-up gives a power boost. Early levels are quick; later levels take longer and get harder over time.
- Simple start (v1): upgrades come only from levelling up. No hidden-gem skill points, no ability slots, no morphs. Add these later if the game needs more depth.
- Power levels: 3 power levels per character level, for now (to be confirmed: each character level holds 3 power upgrades, spread across digging, building, and inventory).
- How each power grows (from your son's ideas):
  - Digging: dig with a shovel or pickaxe. Each dig adds progress toward the next digging level.
  - Fighting: use a sword to fight. Each fight adds progress toward the next fighting level. (New power, added from your son's ideas.)
  - Building: place blocks to build things. Each block placed adds progress toward the next building level.
  - Progress meters: each power has a visible bar or meter that fills as the player works, so the player can see how close they are to the next level.
  - Inventory: carry items at full capacity for a long time. Progress builds while the inventory is full. (The phrase "work out" was used here; treat as "build up" for now and confirm.)
