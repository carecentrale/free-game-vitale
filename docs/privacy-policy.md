# Privacy Policy: Kids Game

Last updated: (date you publish this)

This game is made for children, and it is designed to collect no personal information.

- **We collect no personal data.** The game does not ask for a name, email address, age, location, photos, or contacts.
- **No accounts.** Players are not asked to sign in or create an account.
- **No chat.** Players cannot type messages to each other. Names are chosen from a preset list.
- **No ads and no purchases.** The game contains no advertising and no in-app purchases.
- **No third-party tracking.** The game does not use analytics or advertising software.
- **Saved progress** (such as the character's name, levels, and gems) is stored only on the player's device and is never sent anywhere.

If the game changes in a way that affects this policy, this page will be updated and the date above will change.
